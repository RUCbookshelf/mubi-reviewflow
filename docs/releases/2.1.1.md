# 2.1.1 upgrade and rollback

## Upgrade

Install the 2.1.1 package for your platform. Existing tasks, decisions, coding, evidence and uploaded originals remain in their current data directory. Back up the data directory before an application upgrade; stop other backend processes before copying databases.

Import review adds migration 3: `workflow_import_undo`. The migration is additive and idempotent. Before creating the table, the database receives a SQLite backup beside it named `<database>.pre-import-undo-v3.bak`. Migration 1 and 2 remain intact. Undo snapshots cover affected incoming provenance and bibliographic metadata; they do not replace screening or coding records. An owner can undo only an eligible last review before activation, provided the policy version and affected state still match.

## Rollback

Preserve the complete current data directory, including newer work, attachments, uploaded originals and the new history table before rolling application code back. The added table is harmless to 2.1.0 code. An older client will not expose import-review Undo or the new layouts. Continue to observe current owner policies and activation state.

Never overwrite post-upgrade research data with the pre-migration backup. Use that backup only for a deliberate maintenance recovery after preserving newer work and reconciling it separately.

## Scope

Import and export page layouts and labels, the floating import checklist, runtime version footer, and guarded import-review Undo. Existing import matching, screening, coding, analysis and file-export algorithms are unchanged. Original controls and download routes are retained; the title-candidate list has an additive `view=all` option for completed history.

## Verification

Changed Python, JavaScript, inline scripts, CSS and new ten-language dictionaries receive static checks. Manual visual inspection uses disposable data and a separate preview server, including desktop and mobile widths. No automated tests are added or run for this delivery. GitHub Actions builds the three platform packages from the tagged source commit.
