## 1. 连续排除规则(streak-n)的解析安全界

### 1.1 模型与精确闭式

**无信息随机序假设(null model)**:筛序是 N 条记录的均匀随机排列,即排序模型
不携带超越患病率的信息;标签序列在全部 C(N,K) 个二值序列上均匀。

规则语义:首次出现连续 n 条排除即停(ASReview 内置准则 / Kempny 准则 2 语义)。

**引理 1.1(gap 分解)**:设 K 条相关的筛序位置 z_1<…<z_K,排除段
g_0 = z_1−1,g_i = z_{i+1}−z_i−1(i=1..K−1),g_K = N−z_K。则

> 遗漏事件(停时未看全 K 条相关)⟺ max(g_0,…,g_{K−1}) ≥ n。

证明:任何 ≥n 的排除游程必整段落在某个 gap 内;若某前 K 个 gap ≥ n,读序时
该游程在第 K 条相关之前完成 ⇒ 触发停止且 z_K 未读 ⇒ 遗漏。反之若前 K 个 gap
全 < n,则第 K 条相关读入之前不可能触发。∎
(注意:尾 gap g_K 在所有相关之后,不影响安全性。)

**定理 1.1(精确闭式)**:随机序下

```
P_miss(n, K, N) = 1 − (1/C(N,K)) · Σ_{j=0}^{K} (−1)^j · C(K, j) · C(N − j·n, K)
```

(约定 C(a,b)=0 当 a<b;求和实际在 j > (N−K)/n 时截断。)

证明:满足"前 K 个 gap 全 ≤ n−1"的放置数由容斥计数——恰有 j 个指定 gap ≥ n
时,从这些 gap 各抠出 n 个排除位,剩余 N−jn 个位置选 K 个相关位:C(N−jn, K)。
对 C(K,j) 求容斥和,除以全放置数 C(N,K)。∎
手工枚举对账:N=4,K=2,n=2 → 1/3;N=3,K=1,n=2 → 1/3;N=4,K=1,n=2 → 1/2
(`check_d1_streak.py` §2,逐位相等)。蒙特卡洛对照(2 万次,5 倍标准误容差)
12/12 格全过(`check_d1_streak.py` §1)。

### 1.2 与超几何 / 几何-负二项的联系

- 边际上,P(g_0 ≥ n) = C(N−n, K)/C(N, K) = Π_{i=0}^{n−1}(1 − K/(N−i)) ≤ (1−p)^n
  ——有限总体无放回的**超几何**衰减;对任意前 K 个 gap 同理。
- **union-bound 安全式**:P_miss ≤ K·(1−p)^n ≤ α ⟺

```
n ≥ ln(K/α) / (−ln(1−p)) ≈ ln(K/α)/p    (p 小)
```

- 大 N 近似(泊松聚集启发):P_miss ≈ 1 − exp(−K(1−p)^n)。"连续 n 条排除"的
  等价叙述:第 n+1 条排除前未遇相关的等待时间服从几何/负二项族——这正是
  SWIFT 类估计器把发现过程建为负二项的同一骨干(§3.3)。

### 1.3 数值:无信息基线在真实参数下几乎没有安全

精确闭式(α=0.05 数值反解 vs union-bound 近式,`check_d1_streak.py` §3–4):

| 数据集 | N | K | P_miss(n=10..100) | n_safe(精确) | n_safe(近式) |
|---|---|---|---|---|---|
| Bos_2018 | 4878 | 10 | n=10..100 全部 ≈1.0000 | **2005** | 2582 |
| Appenzeller-Herzog_2019 | 2873 | 26 | 同上 ≈1.0000 | **612** | 688 |
| van_der_Waal_2022 | 1970 | 33 | 同上 ≈1.0000 | **349** | 385 |
| Nelson_2002 | 366 | 80 | n=25:0.127;n=50:0.0001 | **29** | 30 |

解读:**若排序不携带信息,任何实用阈值(10–100)在低患病率集上都近乎必然遗漏**;
要达到 95% 安全,Bos 需 streak ≈ 2005。union-bound 近式一致偏保守(安全侧),
相对差 15%–29%。泊松近似 1−exp(−K(1−p)^n) 的最大绝对误差 0.058(记录值,
低患病率大 N 端偏保守)。

### 1.4 它是 AL 序的乐观/非保守基线 —— 对 Kempny 2026 的解释

随机序假设给出的是**规则的"模型无关贡献" ≈ 0**(低患病率下)。三层含义:

1. **作为安全证书:乐观(非保守)。** AL 筛序不是可交换序:排序后各位置的
   排除概率既不独立也不同分布;更关键的是 streak 的产生与模型误差**内生耦合**
   ——模型把"看起来不相关"的记录压到队尾,恰好当它判错(漏相关的特征学不
   到)时才会形成长 streak。因此"已连续排除 n 条,说明尾部干净"是关于**模型
   信念**的陈述,不是关于**池构成**的陈述。把 §1.1 的闭式(或其几何直觉
   "(1−p)^n 很小")搬用到 AL 序上作安全声明,证书在模型失配时恰巧失效——
   保守性丢失的方向。
2. **作为点估计:双向失真,无迁移性。** 好模型下 AL 的遗漏率远低于随机序
   基线(Bos 实测 streak=50 遗漏率见试点报告);坏模型/难数据下可更差。
   差值 = 模型贡献,随数据集、模型、训练动态变化,**不由 n 控制**。
3. **Kempny 2026 的观测正落在此处**:其准则 2(连续排除)的"安全阈值"
   (以 n*/N 计)在不同数据集间 2%–61% 波动,准则 1(按估计总数停)仅 2%
   模拟可靠;准则 3(固定比例)无普适值。同一阈值不可能同时是安全的——
   因为安全性是模型的函数,不是规则的函数。

**设计结论**:streak 规则只能作廉价辅助闸门,不能承载安全职责;安全须由
显式统计证书提供(§2、§4)。试点将把每条 AL 轨迹的 (n, 遗漏率) 经验点画在
随机序零模型曲线上,直观量化"模型贡献了安全层的多少"。

## 2. 随机子样患病率估计器 + 序贯监测(设计式证书)

### 2.1 单点证书

监测时刻剩余池 m0 条、未知相关 R0 条。均匀无放回抽 m 条全部人工判读:

```
X | R0=r ~ Hypergeometric(m0, r, m),  P(X=x) = C(r,x)C(m0−r, m−x)/C(m0, m)
```

**引理 2.1(随机占优)**:HG(m0, r, m) 随 r 随机递增(把池中一个失败位换成
成功位的逐点耦合),故 cdf_r(x) = P_r(X ≤ x) 对 r 非增(数值网格验证:
`check_d2_subsample.py` §1)。

**定理 2.1(单点证书的覆盖保证)**:观测 x,检验"R0 ≤ k"取 p 值

```
π_k(x) = sup_{r ≥ k+1} P_r(X ≤ x) = P_{r=k+1}(X ≤ x)   (由引理 2.1,sup 在 k+1 处)
```

若 π_k(x) ≤ α 则宣布"R0 ≤ k"。则对一切真值 R0 ≥ k+1:
P(错误宣布) ≤ α。
证明:错误宣布 ⟺ cdf_{k+1}(X) ≤ α;而 cdf_r(X) ≤ cdf_{k+1}(X)(r≥k+1),
记 x*_r = max{x : cdf_r(x) ≤ α},则 P(cdf_r(X) ≤ α) = cdf_r(x*_r) ≤ α(按
x*_r 定义,离散无损)。∎ 蒙特卡洛:r=1..12 × 1.2 万次,虚证率全过
(`check_d2_subsample.py` §2)。

**推论 2.1(精确上界 / Clopper–Pearson 式)**:U(x) = max{r : cdf_r(x) > α}
满足 P(R0 > U(X)) ≤ α(实现 `ucb_hypergeom`,二分)。

**推论 2.2(零证书 ≈ 普查定理)**:k=0、x=0 时

```
π_0(0) = P_{R0=1}(X=0) = (m0 − m)/m0 ≤ α ⟺ m ≥ (1−α)·m0
```

——**要"证明剩余为零",随机子样必须抽 ~(1−α) 的池,与真值无关**(最难备择
是 r=1)。这是随机子样法的结构性代价:零遗漏目标下的子样证书 ≈ 普查;
必须靠 k>0(召回目标型)或与排序信息结合来减负。

### 2.2 多 look 的序贯校正:Bonferroni 型 α-spending

L 个计划 look(l=1..L),水平 α_l,Σ α_l = α。

**定理 2.2(任意依赖下有效)**:P(∃l: 在真 R0>k 时错误证书) ≤ Σ_l α_l = α。
证明:union bound;不需要 look 间任何独立性——这正是嵌套池、重叠子样、
与 AL 动态耦合的场景所需要的。∎

选型:**α-spending 形状 + Bonferroni 预算**(经典 Lan–DeMets 正态边界需要
独立增量结构,离散超几何 p 值不满足,故只借其形状做预算分配,有效但保守):

- **Pocock(等分,默认)**:α_l = α/L。L=7, α=0.05 → 每 look 0.00714。
- **OBF 形状**:累计 A(s) = 1 − Φ(z_{1−α}/√s),增量 α_l = A(l/L) − A((l−1)/L);
  L=7, α=0.05 → [6.7e-6, 0.0010, 0.0049, 0.0088, 0.0110, 0.0120, 0.0122]
  (早严后松)。实现修正浮点和使 Σ = α 精确成立。

序贯虚证率蒙特卡洛(Pocock/OBF,强依赖 look)全过(`check_d2_subsample.py` §4)。

### 2.3 安全–工作量前沿(解析式)

**(a) 证书式前沿**:k 目标下,单 look 以 x=0 通过证书的最小子样:

```
精确:m*(m0,k,α) = min{m : P_{R0=k+1}(X=0) ≤ α}
近似:m* ≈ m0 · (1 − α^{1/(k+1)})     相对误差 < 1%(实测 ≤0.9%)
```

| m0 \ k | 0 | 1 | 2 | 4 |(α=0.05)|
|---|---|---|---|---|---|
| 2000 | 1900 | 1450 | 1263 | 901 |
| 500 | 475 | 363 | 316 | 225 |
| 150 | 143 | 109 | 95 | 68 |

**(b) 检测式(功效侧)**:真 r 条相关时子样全盲的概率
P(X=0 | r) = C(m0−r, m)/C(m0, m) ≈ (1 − m/m0)^r(最大绝对误差 0.003,实测);
以 1−β 概率"至少抓到 1 条"需 m ≥ m0(1 − β^{1/r})。例:m0=2000、r=5、
β=0.05 → m ≈ 1200。

**结论**:负担由 (1−α)^{1/(k+1)} 主导——k=0 不可负担(§2.1 推论 2.2),
**k 随已发现数增长(recall 目标型 k_t = floor(found·(1−R)/R),见 §4)是唯一
可负担的证书形态**;序贯多 look 主要作用是让 m0 随池缩小而下降,而非提高
单 look 检测力。

## 3. 排序加权估计器

### 3.1 设计式:比例估计与分数加权 HT

- **比例估计**(子样即插即用):R̂0 = (m0/m)·X。无偏(蒙特卡洛偏差 ≤3 标准误,
  `check_d3_estimators.py` §1);
  Var(R̂0) = (m0²/m)·q(1−q)·(m0−m)/(m0−1),q = R0/m0(公式 vs MC 相对误差
  0.011–0.012,§2)。
- **分数校准 HT 估计**:设校准 f(s) = P(relevant | score s)。对剩余池子样 S:

```
R̂0_HT = (m0/m) · Σ_{i∈S} f(s_i),   Var = m0²(1−m/m0)·S²(f)/m
```

  S²(f) 是池内 f 的总体方差。校准好 + 排序可分(尾部 f≈0)⇒ S² 小 ⇒ 方差
  大降(构造示例实测方差公式相对误差 0.005;示例中降为比例估计的 0.79,
  增益随池构成变化,§3)。**抽样设计不变 ⇒ 覆盖保证保持**(对 f 误校准
  稳健的是方差而非偏差——f 只进估计量,不进证书;证书仍按 §2 计)。

### 3.2 引擎记录需求(报告调度会话,不改 replay.py)

分数校准 HT 需要**剩余池的分数分布**;现有轨迹仅记 `model_top_remaining`
(top-5),不足。需要引擎在每训练步补充(成本 O(n)/步,无额外内存压力):

- `remaining_score_sum`:Σ s_i(池内分数和)——支撑"分数和/相关分数均值"型
  快速估计器;
- `remaining_score_quantiles`:[q10,q25,q50,q75,q90] —— 支撑校准查表与
  S²(f) 估计。

### 3.3 与 SWIFT 负二项法的关系;开放实现

SWIFT-ActiveScreener(Cohen 等,商业)以贝叶斯发现过程估计剩余相关数:负二项
= Gamma–Poisson 混合,即"局部发现率 λ 未知(Gamma 先验)+ 窗口计数 Poisson"。
开放实现(本仓库,`stopping_rules.evaluate_nb_window`):

```
窗口 [t−W, t] 内发现 x_w 条 ⇒ 后验 Gamma(a0+x_w, b0+W)(共轭精确)
λ 上界 = Gamma_ppf(conf; a0+x_w, b0+W) ⇒ R0_ub = (N−t)·λ_ub
R0_ub ≤ k_t ⇒ (启发式)停
```

**定位**:模型法,**无设计式覆盖保证**(iid 序下经验覆盖 0.987 @ conf=0.95,
记录值;AL 序下未知 → 试点实证测量,flag=`heuristic_no_guarantee`)。与 §3.2
的关系:NB 用发现时间维度的信息,HT 用分数维度;两者都不承担证书职责,
证书由 §2 的随机子样承担。

## 4. 组合规则(双闸门)

**定义**(主 = 序贯子样证书,辅 = streak):

```
在计划 look t_l:
  闸门 1(免费):当前 exclude_streak ≥ n_streak?否 → 跳过本 look(不抽样、零人工成本)
  闸门 2(证书):从剩余池抽 m 条人工判读,π_{k_t}(x) ≤ α_l?
停 ⟺ 两闸同时通过。k_t = 0(零遗漏模式)或 floor(found_t·(1−R)/R)(召回目标 R)。
```

**定理 4.1(误差单调)**:停止事件 = 证书事件 ∩ streak 事件 ⊆ 证书事件,故

```
P(组合停 | R0 > k_t) ≤ P(证书过 | R0 > k_t) ≤ Σ α_l = α
```

与 streak 闸门和证书的任意相关结构无关(交集单调;MC 验证,
`check_d4_combined.py` §1)。

**效率语义**:闸门 1 在模型明显未收敛期(队头仍高频出相关)阻止无效抽样,
节省 m×(被挡 look 数) 的人工;代价是证书已过但 streak 未满时最多多筛
n_streak 条。试点将报告 blocked_looks 分布与净成本。

**理论↔实现闭环**:`check_d4_combined.py` §3 在随机序合成轨迹上运行
`evaluate_streak`,经验遗漏率与 §1 闭式一致(容差内)——后评估实现与理论
同一口径。

## 6. Kempny 2026 复现语义(PubMed 42106619 / PMC13156873,CC-BY 全文)

原文三准则(BMC Med Res Methodol 2026;26:109,ASReview v1.6.1,5 个 SYNERGY
集,初始子样本 1%–30% × 1000 模拟 = 35,000 次):

1. **准则 1**(SYMBALS 型"按估计总数停"):初始随机样本估患病率 →
   估计相关总数 T = round(x_s/s·N),筛到找到 T 条即停。结论:仅 2% 模拟可靠。
2. **准则 2**(连续排除):报告每条轨迹"最后一条相关之前的最大排除游程 n*"
   即安全阈值(以 n*/N 百分比计),跨数据集 2%–61% 波动。
3. **准则 3**(固定比例停):无普适比例。

我们的复现(实现:`evaluate_kempny_c1` / `kempny_k2_safe_threshold`):

- 准则 1:**语义同构**。差异(如实标注):Kempny 用初始样本充当 ASReview
  先验/训练集;我们轨迹为 preset=asreview(先验 (1,1)),样本仅作估计源 +
  额外人工成本,不回灌模型;T=0 退化态(样本零相关 → 立即停、漏全部)按
  其语义保留(flag=`degenerate_zero_estimate`)——这正是其"2% 可靠"的
  主要来源之一。随机序下可靠率有闭式:P(无遗漏) = P(x_s ≥ ⌈(K−½)s/N⌉)
  (超几何尾;测试与 MC 一致)。
- 准则 2:**按其回顾式安全阈值语义复现**(n* 提取器,非停规则),并直接给出
  阈值-n* 的遗漏等价:n ≤ n* 必遗漏,n > n* 必安全(测试断言)。
- 协议差异汇总:5 集 vs 我们试点 4 集(重叠 Bos / Appenzeller-Herzog /
  van_der_Waal);其先验=大样本(1%–30%)vs 我们 (1,1);其 1000 模拟/格 vs
  我们 10 种子(试点)。全量(26 集 × 25 种子)后再做定量对照。
