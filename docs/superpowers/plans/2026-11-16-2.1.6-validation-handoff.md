1. manifest before/runtime/after；runtime实际 `module.__file__`、该文件bytes/SHA和加载路径，不能只结束后扫hash冒充运行时采样。清楚区分stdlib/venv依赖与批准产品源。

### R26-I　完整入口的真实child隔离

这是单独可拒收的P26子包，作者Luna、测试g-flash、产品/测试分别DeepSeek独审，文件锁：`build/run_validation.py` 及 `build/tests/test_2_1_6_release_workflow.py` 中受影响真实argv/计划行为断言；必要入口专测新建 `build/tests/test_216_validation_child_isolation.py`。不改workflow权限、八步数量、fail-fast或validator集合。

当前 `[sys.executable, '-m', 'pytest', ...]` 不继承父-I/B。补为显式隔离child，唯一受信src root由入口REPO传给固定bootstrap；module/script两种均真实argv导出，不在注释假放flag：

```python
PY_CHILD_BOOTSTRAP = (
    'import runpy,sys;'
    'root=sys.argv.pop(1);kind=sys.argv.pop(1);entry=sys.argv.pop(1);'
    'sys.path.insert(0,root);sys.argv[0]=entry;'
    "runpy.run_module(entry,run_name='__main__') if kind=='module' "
    "else runpy.run_path(entry,run_name='__main__')"
)
# pytest step argv:
[sys.executable, '-I', '-B', '-c', PY_CHILD_BOOTSTRAP,
 str(REPO), 'module', 'pytest', 'build/tests', '-q']
# Python validator step argv:
[sys.executable, '-I', '-B', '-c', PY_CHILD_BOOTSTRAP,
 str(REPO), 'script', str(REPO / rel)]
```

实际新箱child探针输出sys.flags.isolated/dont_write_bytecode、cwd、sys.path、__file__，确认只引受信REPO、无主仓fallback；保旧missing-node exit2、整目录一进程/六validator/24Node和真实子进程非零行为。测试解析实际plan/运行真实child，删-I或删任一validator必须变异红。bootstrap只接固定kind和入口枚举，不接受客户端任意script。CI与本地仍用相同入口，没有“本地换个执行器绿”的分叉。

所有其他R26修复只有被独立复现的当前缺口才能创建；在MAINTENANCE_GATE_MATRIX中给ID/owner/files/依赖与验收。已闭项仅引用证据，外部项不强行变产品修改。

```text
包<ID> / 阶段 IMPACT_AND_PLAN；不是CODE。
```

CODE、REVIEW、RUN_PACKET是后继独立消息，不能一条prompt在未有影响结果时就授权全部步骤。主控向用户报告风险后可在既有维护范围内继续，不重复请求已经给过的业务决定。自动完成通知只是内部状态，不是外部发布或新人类授权。
