# Mubi·ReviewFlow 2.1.2

## 中文

- 首批记录就绪后即可核验，其余记录在后台分批加载。
- 紧凑圆环显示真实加载数量；中断后保留已加载记录并支持重试。
- 后台加载保留当前记录、选项、展开内容和滚动位置。加载提示支持十种语言，页脚同步实际版本。

## English

- Review the first available records while the remainder loads in small background batches.
- A compact animated ring shows actual loading counts. Interrupted loading retains available records and can be resumed.
- Background loading preserves the current record, choices, expanded details and scroll position. Loading labels support ten languages; the footer shows the running version.

## Français

- Un indicateur circulaire compact affiche les quantités chargées. En cas d’interruption, les enregistrements sont conservés et le chargement peut reprendre.
- Le chargement conserve le choix, les détails ouverts et le défilement. Les libellés couvrent dix langues et le pied de page affiche la version.

- Сохраняются выбор, раскрытые сведения и прокрутка. Поддерживаются десять языков; версия указана внизу страницы.
