# ReviewFlow 前端更新说明 · 20260929-ui3

基线：本次对用户已替换的 `custom_frontend_unified.zip` 继续修改。此包是完整的 `custom_frontend/` 替换目录，不是补丁，也不是静态演示。新增代码没有引入构建步骤、第三方依赖或远程服务。

## 更新内容

### 1. 工作区层级与名称

“首页与设置”是全局入口，独立于“筛选／编码／分析”三个阶段。阶段下面是实际存在的页面；数据分析再分为方法模块和具体方法。任务名单独显示为当前数据上下文，不作为功能目录、同级页面或测试名称写死。

页面标题、侧栏、顶部路径和同级菜单统一读取 `navigation_registry.js`。阶段菜单只含三个阶段；实际页面和方法类别可以点击返回；悬浮或点击独立展开按钮只显示对应层级的同级项。支持键盘方向键、Home/End、Escape、点击外部关闭、触屏和浏览器前进后退。保留旧 `#an...` 锚点兼容。

### 2. 分析功能分类

8 个模块、31 个方法入口：数据准备、效应量计算、总体效应合并、异质性与调节分析、敏感性分析、发表偏倚检验、专题分析与证据综合、报告与审计。

完整层级图及设计约束见 `NAVIGATION_MAP.md`。两张独立 Mermaid 图保存在 `docs/`。这是产品导航的分类，不表示每篇论文必须采用全部方法。异质性页面显示现有合并结果，不新增算法或独立生成检验值；旧结果会保留原模型、范围及“上次运行结果”标记。

### 3. “全部方法”目录

原“显示全部”不再展开全部表单。新入口显示真实的方法数量，打开按模块分组的可搜索目录。重复点击仍停留在目录；显式“返回当前方法”和 Escape 可返回，并恢复必要的滚动位置与编辑草稿。切换、搜索和返回不发起统计请求。只使用约 150 ms 的轻量过渡，并响应系统的减少动态效果偏好。

### 4. 背景颜色

所有工作区的页面底色使用 `--bg`，编辑面板使用 `--surface`，柔和子区域使用 `--surface-subtle`。清除了普通工作区透出登录页米色画布的问题。

阅读器周边使用独立的 `--reader-stage`，PDF 纸张及出版图保留白底。未修改 SVG/Canvas 图形填色、导出算法或原文高亮；纳入、待定、排除、警告和手动覆盖继续保留语义色。深色主题下主操作和危险操作的文字前景也按对应底色调整，保持可读性。登录品牌背景独立保留。

### 5. 关联可见性和状态修复

- 替代录入方式不再隐藏必需的来源报告、页码和方向控件。
- 单组计数、二分类、剂量、网络、个体数据入口按各自原处理函数显示共用研究和来源控件；不增加新的保存字段。
- 零单元格页面可直接录入原事件数；数值输入具有持续可见的标签。预览仍调用原接口。
- 分类切换时，共用探索性分析控件保留各自的结果；改变范围或数据后清除对应缓存，迟到响应不会显示为另一项分析的结果。
- 切换任务后，单方法页面不会留下无法操作的空隐藏方法选择器；模型、数据和结果仍按原任务重置机制处理。

## 检查范围

在 Chromium 中离线装载实际页面、样式与脚本，使用隔离的测试接口响应验证。浏览器导航环境限制了 localhost/file URL 访问，因此测试使用 `page.set_content` 装载方式；测试替身、虚构任务、测试脚本和测试数据均不包含在交付目录中。

通过的浏览器检查：522 条断言，来自工作区/导航回归 339 条、结果与编辑流程 40 条、输入模式与必要控件 77 条、颜色/语义面检查 66 条。另有 62 个 JavaScript 语法单元通过检查；接口字符串集合与基线相同，原静态输入和按钮 ID 没有丢失，运行时没有重复 ID。

覆盖 10 个工作区、31 个方法入口、8 个分析模块、9 种效应量录入模式；视口 1440、1280、768、390 px；明暗主题、导航语种和输入/枚举稳定性、历史前进后退、旧锚点、菜单鼠标/键盘/触屏、搜索空态、减少动态效果、取消/应用模型、旧结果、重跑失败以及异步响应隔离。

这不是完整生产环境验收。未连接真实统计后端，未重新验证真实研究结果、登录权限、真实 PDF 渲染/批注保存或 Word/PowerPoint/LaTeX 报告输出。10 语种的新导航文案已接入既有语言机制，但本次不等同于全应用所有动态后端消息的专业译审。

## 替换与回退

1. 备份当前完整 `custom_frontend/`。
2. 用压缩包中的同名目录整体替换前端；不要覆盖后端、数据库、上传目录、环境配置或用户研究数据。
3. 沿用原项目的启动方式。脚本和样式资源版本为 `20260929-ui3`；清除旧 HTML 缓存并强制刷新。若有反向代理或服务工作线程缓存，还需使原部署缓存失效。
4. 在原环境至少完成一次“选择已有任务—打开方法—运行—编辑后取消/应用—重新运行—导出”和一次实际 PDF 阅读/保存的联调；正式替换前对比原版与新版同一输入请求和结果。
5. 回退时恢复备份的整个前端目录，并再次使旧 HTML/资源缓存失效；本次无需数据库迁移。
